# EcoV Charge

[한국어](README.md) · [English](README.en.md) · [ไทย](README.th.md)

> แอปชาร์จรถยนต์ไฟฟ้าอัจฉริยะที่ยังคงความสะดวก พร้อมช่วยลดการปล่อยคาร์บอน

EcoV Charge ช่วยลดคาร์บอนฟุตพรินต์จากการชาร์จรถยนต์ไฟฟ้า โดยใช้ข้อมูลความเข้มข้นของคาร์บอนในโครงข่ายไฟฟ้า เพื่อช่วยให้ผู้ขับขี่ชาร์จในช่วงเวลาที่สะอาดกว่า โดยไม่ทำให้การใช้งานยุ่งยากขึ้น

## คุณสมบัติ

- **ขั้นตอนการชาร์จที่เรียบง่าย**: ดูสถานะรถ ระดับแบตเตอรี่ปัจจุบัน และขีดจำกัดการชาร์จได้ในที่เดียว
- **ดูความเข้มข้นของคาร์บอนในโครงข่ายไฟฟ้า**: ดูค่าปัจจุบันและการคาดการณ์ล่วงหน้า 6 ชั่วโมงผ่านกราฟ
- **ข้อมูลตามตำแหน่ง**: ใช้ตำแหน่งของอุปกรณ์เพื่อระบุประเทศและข้อมูลโครงข่ายไฟฟ้าในภูมิภาค
- **ช่วงเวลาชาร์จที่สะอาดกว่า**: แสดงช่วงเวลาที่มีการปล่อยคาร์บอนโดยประมาณต่ำกว่า
- **รองรับหลายแพลตฟอร์ม**: รันแอปบน iOS, Android และ Web ด้วย Expo

## วิธีใช้งาน

1. เปิดแอปและอนุญาตให้เข้าถึงตำแหน่ง
2. ตรวจสอบตำแหน่งและความเข้มข้นของคาร์บอนในโครงข่ายไฟฟ้าจากหน้าหลัก
3. แตะ `Start charging` เพื่อเปิดหน้าชาร์จ
4. ตรวจสอบขีดจำกัดและสถานะการชาร์จ จากนั้นเริ่มหรือหยุดการชาร์จ

หากยังไม่ได้ตั้งค่า Electricity Maps แอปจะแสดงผลโดยใช้ข้อมูลคาดการณ์สำรองในเครื่องแทน

## เทคโนโลยีที่ใช้

- [Expo SDK 54](https://docs.expo.dev/versions/v54.0.0/) / React Native 0.81
- React 19.1 และ React Compiler
- การกำหนดเส้นทางแบบไฟล์และ Typed Routes ด้วย Expo Router
- Bun 1.3 สำหรับจัดการแพ็กเกจและเรียกใช้สคริปต์
- คอมไพเลอร์ TypeScript 7 แบบ native พร้อมการตรวจสอบความเข้ากันได้ด้วย TypeScript 5.9
- Oxlint และ Oxfmt ที่ทำงานบน Oxc

## เริ่มต้นใช้งาน

### สิ่งที่ต้องมี

- [Bun](https://bun.sh/) เวอร์ชัน 1.3 ขึ้นไป
- Node.js LTS
- Expo Go หรือสภาพแวดล้อมพัฒนาแบบ native สำหรับทดสอบบนมือถือ

### ติดตั้งและรัน

```bash
bun install
bun run dev:clear
```

เมื่อเซิร์ฟเวอร์พัฒนาทำงานแล้ว ให้กด `i`, `a` หรือ `w` ในเทอร์มินัลเพื่อเปิด iOS, Android หรือ Web ตามลำดับ

หรือเรียกใช้แต่ละแพลตฟอร์มโดยตรง:

```bash
bun run ios
bun run android
bun run web
```

### ตัวแปรสภาพแวดล้อม

ดูตัวอย่างจาก `example.env` แล้วสร้างไฟล์ `.env` ที่โฟลเดอร์รากของโปรเจกต์ จากนั้นตั้งค่าข้อมูล API ของ Electricity Maps

```dotenv
EXPO_PUBLIC_ELECTRICITYMAPS_API_URL="https://api.electricitymaps.com/v4"
EXPO_PUBLIC_ELECTRICITYMAPS_API_KEY="YOUR_API_KEY_HERE"
```

หากต้องการใช้ reverse-geocoding endpoint อื่นบน Web ให้เพิ่มตัวแปรนี้ได้ (ไม่บังคับ):

```dotenv
EXPO_PUBLIC_LOCATION_GEOCODER_URL="https://your-api.example.com/reverse"
```

### ตรวจสอบคุณภาพโค้ด

```bash
bun run lint
bun run format:check
bun run typecheck
bun run check
```

ตรวจสอบความเข้ากันได้กับ Expo:

```bash
bunx expo-doctor
```

## โครงสร้างโปรเจกต์

```text
.
├── assets/          # ไอคอนแอปและรูปภาพคงที่
├── src/
│   ├── app/         # หน้าจอและ layout ของ Expo Router
│   └── packages/    # โมดูลตำแหน่งและ Electricity Maps API
├── app.json         # การตั้งค่า Expo
├── example.env      # ตัวอย่างตัวแปรสภาพแวดล้อม
├── package.json     # สคริปต์และแพ็กเกจที่ใช้
└── tsconfig.json    # การตั้งค่า TypeScript
```
